# booking-ui

Single-page web client of Office Booking, built with React 19, TypeScript and Vite.

- Sign-in form; the JWT is kept in the browser and sent with every API request
- Users see areas and desks and book a desk for today
- Administrators also create, edit and delete areas and desks

## Run

The API must be running on http://localhost:9010 (see the root README).

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
```
